What measurement changed

        
    
          
  • Fixed-size chunking beat recursive and semantic — hit@1 1.00 vs 0.82 vs 0.64. Fixed windows keep a circular's header and body together by accident of overlap.
    • 
          
  • Contextual chunk headers hurt — every chunk of a circular shares the header, chunks collapse together, document diversity drops.
    • 
          
  • Dense retrieval cannot see exact identifiers — six near-identical sanctions circulars are interchangeable to an embedder; BM25 + RRF fixes it, the reranker seals it.
    • 
          
  • Cosine cannot gate in-domain-unanswerable questions — the repo-rate question scores 0.7 against deposit-rate circulars; the reranker scores it 0.09 and refuses before any LLM call.
    • 
          
  • Qdrant's RRF uses k = 1, not 60 — measured, and the local fusion is kept congruent by a test.
    • 
          
  • Models invent citation syntaxes — [1], 【5】, bold-with-no-brackets, and on the first live Fargate request 【1†L9-L12】. Compliance is a metric, not a hope.
    • 
          
  • Thresholds are per score scale — the same constant was silently read on the wrong scale three times.
    • 
          
  • The primary LLM changed three times with no code change — Bedrock → Anthropic → Gemini, all through the gateway config; Groq is automatic fallback.
    • 
          
  • Free tiers are demo tiers — Gemini allows 20 requests/day; the failover indicator above is that fact made visible.
    •
